HOW TO USE
  * Game engines: drop the PNGs (or the spritesheet) into your project. Turn
    OFF texture filtering / smoothing (use "Nearest" or "Point") so the pixels
    stay sharp. Scale by whole numbers (2x, 3x, 4x...).
  * Unity: Texture Type = Sprite, Filter Mode = Point, Compression = None.
  * Godot: Project Settings > Rendering > Textures > Default Texture Filter =
    Nearest (or set per-node). Use the spritesheet with an AtlasTexture, or
    import single PNGs.
  * Web / apps: use the 32px or 64px PNGs with CSS "image-rendering: pixelated".
  * Videos / slides: the 64px files are the easiest to place.
  * Colors: 21-color palette, 1px dark outline, light source at top-left.

使い方
  * ゲームエンジン: PNG(またはスプライトシート)をプロジェクトに入れ、テクスチャの
    フィルタ(スムージング)を切ってください(Nearest / Point)。拡大は整数倍で。
  * Unity: Texture Type = Sprite、Filter Mode = Point、Compression = None。
  * Godot: プロジェクト設定 > Rendering > Textures > Default Texture Filter を
    Nearest に(ノードごとの設定でも可)。スプライトシートは AtlasTexture で。
  * Web・アプリ: 32px か 64px の PNG を CSS の image-rendering: pixelated で。
  * 動画・スライド: 64px のファイルが置きやすいです。
  * 色: 20色のパレット(RGB の値は英語の STYLE NOTES に一覧)。輪郭は1ドットの
    濃い色、光は左上から、影は右下。自分のプロジェクト用に色を変えてもかまいません。
